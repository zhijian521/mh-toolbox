# 梦幻游戏资料

梦幻西游相关的静态资料按主题放在本目录，每类资料只维护一份，供页面和领域规则导入使用。

| 文件                    | 内容                                                           |
| ----------------------- | -------------------------------------------------------------- |
| `schools.js`            | 门派列表、门派选项和默认门派                                   |
| `school-skills.js`      | 各门派师门技能名称                                             |
| `character-progress.js` | 辅助技能、人物修炼和召唤兽修炼项目                             |
| `quick-items.js`        | 收益页速记物品目录（固定价格组 / 不固定价格组）与图标映射      |
| `quick-catalog.js`      | 速记物品的纯数据（id / 名称 / 图标名），领域层唯一可依赖的那份 |
| `price-catalog.js`      | 物价页的分类与内置物品目录                                     |

新增装备、宝石、特技、等级和消耗表等资料时，继续按主题新建文件。数据定义与计算、校验、保存逻辑分开，不在页面重复维护相同名单。

导出的资料作为只读模板使用；需要编辑或为领域实例提供可修改数据时先复制。角色实际等级、装备档案等用户数据不保存在这里。

当前内容原样整理自 V2 已有的初始迁移资料，不代表在整理时重新核实了游戏内容。原始来源说明见 V1 归档的 `docs/SCHOOL_TEMPLATES.md`（归档已从工作区移除，取法见 `docs/SYNC.md`）；后续修改须记录资料来源和核对时间，并通过对应回归测试。

完整约束见 `docs/ARCHITECTURE.md` 的「游戏资料集中维护原则」。
