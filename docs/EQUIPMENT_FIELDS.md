# 装备属性字段

字段规则集中在 `src/renderer/js/core/equipment-fields.js`。手动新增、编辑和截图核对共用 `UI.equipmentEditor`，显示值按游戏原样记录，不反算初始属性或混合宝石的贡献。

## 按部位填写

| 部位 | 主要属性 | 附加属性 / 强化 |
| --- | --- | --- |
| 武器 | 伤害、命中 | 最多两条体质/魔力/力量/耐力/敏捷，可为负数；特技、特效、宝石及熔炼 |
| 头盔 | 防御、魔法 | 特技、特效、宝石及熔炼 |
| 衣服 | 防御 | 最多两条人物属性，可为负数；特技、特效、宝石及熔炼 |
| 项链 | 灵力 | 特技、特效、宝石及熔炼 |
| 腰带 | 防御、气血 | 特技、特效、宝石及熔炼 |
| 鞋子 | 防御、敏捷 | 特技、特效、宝石及熔炼 |
| 戒指 | 伤害或防御 | 最多三条进攻类词条，允许同名；精炼、超级简易、钟灵石及套装 |
| 耳饰 | 法术伤害或法术防御 | 同戒指 |
| 手镯 | 封印命中等级或抵抗封印等级 | 最多三条防守类词条，允许同名；精炼、超级简易、钟灵石及套装 |
| 佩饰 | 速度 | 同手镯 |
| 玉魄·阳 | 一条进攻类主属性 | 最多两条进攻词条、灵尘、奇袭概率、开光孔及灵契 |
| 玉魄·阴 | 一条防守类主属性 | 最多两条防守词条、灵尘、奇袭概率、开光孔及祝符 |
| 其他 | 自定义原文 | 仅存入仓库 |

宝石类型按部位限定，每件最多两种。总锻炼等级和已知单种等级分别记录，无法确定单种等级时留空。主要属性按游戏当前值填写，「宝石增加的属性」用于游戏另外列出的数值；系统不把两者相加。灵饰和玉魄的词条数值与方括号加成分别保存。钟灵石后的单件效果和套装数值不占灵饰附加词条。

五行、耐久、修理次数、制造者、符石/星位与套装文字放在「其他信息」。未收录的旧属性和特效保留为待核对原文；当前规则覆盖常见字段与所附 12 张截图，不承诺穷尽所有活动装备和特殊版本的词条。新增规则时先确认适用部位，再扩展字段定义和样本。

## 数据与兼容

顶层 `schemaVersion: 6`，装备新增 `details.version: 1`：

- `base / extra / bonus / melt`：`{ key, value, boost }[]`，稳定英文属性键，数值为整数，未录入的可选值为 `null`；负数只允许常规装备的附加或熔炼词条。
- `technique / effects[]`：特技与特效；`forge / gems[]`：总强化等级与 `{ type, level }`。
- `clock: { name, level }`、`suit`：钟灵石及单件/套装文字。
- `jade: { dust, assault, chance, holes, enchantments[] }`：灵尘、奇袭、0～3 个孔与对应强化；奇袭概率为 0～100 的百分数。
- `element / durability / repair / maker / runes / legacy`：元信息及无法明确映射的旧内容。

读取旧装备只生成展示投影，不修改原档案。编辑保存后才写 `details`，并生成兼容的 `attributes / special / gems / jade` 快照。原装备 ID、三套方案引用、OCR 原文和交易记录继续保留。版本 5 首次写入新版本前自动生成 `data.json.before-equipment-fields-时间戳.bak`。

空值与 0 分开保存，不完整数字不转换为空值。各部位和截图保留独立 DOM 草稿；正在编辑的部位校验通过后才能保存。切到其他部位保存时仅保存当前部位；丢弃关闭仍需确认。所有写入沿用串行事务和失败回滚。

## 样本与来源

`tests/fixtures/equipment-ocr/` 包含用户提供的六件装备、四件灵饰与阴阳玉魄截图。`samples.json` 为人工转录的字段参考，领域测试验证结构化解析；`equipment-ocr.electron.cjs` 另外使用真实本地引擎验证 12 张图片及核对表单。OCR 仍可能误读耐久、制造者或套装文字，保存前需对照原图核对，不用参考文本覆盖真实识别结果。

规则核对来源：

- [官方宝石说明](https://xyq.163.com/introduce/dj008.html)：镶嵌部位与宝石类型。
- [官方装备特技与特效](https://xyq.163.com/introduce/jn002.html)：特技名称、特效及互斥关系。
- [官方灵饰说明](https://xyq.163.com/introduce/2014/11/6/5015_474275.html)：灵饰分类与星辉石强化。

来源未覆盖的词条不根据画面猜测，旧值保留原文；规则变更需同步领域校验、共用编辑器、展示与回归样本。
