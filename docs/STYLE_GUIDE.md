# 梦幻养老助手 · 界面风格规范（STYLE_GUIDE）

> 一句话定调：**一本摊开的宣纸账本**——墨字、朱砂、竹青、赭金，细线分区，无渐变、无阴影、无 emoji。
> 本文档是样式改动的唯一依据：先改文档，再改 `styles.css` 的 Token，最后才动组件。

---

## 1. 设计关键词

宣纸 · 账本 · 墨字 · 印章朱砂 · 细线 · 紧凑

## 2. 色板（Design Tokens）

所有 Token 定义在 `src/renderer/styles.css` 的 `:root`，改风格只改这里。

### 纸与墨（中性色）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f2ecdd` | 页面底（米白宣纸） |
| `--paper` / `--panel` | `#fbf7ec` | 卡片、顶栏、弹窗表面 |
| `--paper-2` / `--panel-2` | `#f5efdf` | 次级表面、表头、悬停 |
| `--panel-3` | `#ece3cc` | 侧栏、深层表面 |
| `--ink` / `--text` | `#2f2a24` | 主文字（墨黑，非纯黑） |
| `--ink-2` | `#6b6353` | 次级文字 |
| `--ink-3` / `--muted` | `#9a917e` | 弱化文字、提示 |

### 线

| Token | 值 | 用途 |
|---|---|---|
| `--line` / `--border` | `#d9cfb6` | 常规边框、内容分割线、表格行线 |
| `--line-2` / `--border2` | `#c2b58f` | 强调边框、输入框 |

### 语义色（全站仅此四类彩色）

| Token | 值 | 用途 |
|---|---|---|
| `--green` | `#4a7c59` | 收入、成功、已完成 |
| `--red` | `#b33a3a` | 支出、危险、侧栏选中标记 |
| `--gold` / `--gold2` | `#a67c2e` / `#8a6322` | 高亮、进度、排行、焦点 |
| `--blue` | `#3d5a6c` | 养成目标徽章（黛青，非亮蓝） |
| `--purple` | `#8a5a2b` | 装备目标徽章（赭石） |

**禁止出现的颜色**：蓝紫渐变、亮蓝 `#3b82f6`、霓虹色、大面积纯黑 `#000` / 纯白 `#fff`。

## 3. 字体

全局使用内置开源字体 **霞鹜文楷屏幕版**（LXGW WenKai Screen v1.530，OFL 1.1 许可，允许随应用分发、免费商用）：

| 场景 | 字体栈 |
|---|---|
| 全局正文 / 标题 / 数字 | `"LXGW WenKai Screen" → "Microsoft YaHei" → sans-serif`（`--font-body` 与 `--font-serif` 同源，保留双变量便于日后分化） |

- TTF 内置于 `src/renderer/assets/fonts/`，通过 `@font-face` 本地加载，不联网、不依赖系统字体。
- 单一 Regular 字重内置；`font-weight: 600/700` 由浏览器合成加粗（勿在 @font-face 声明全字重区间，否则会禁用合成粗体）。
- 数字保持 `font-variant-numeric: tabular-nums` 声明（字体不支持时自动回退比例数字）。
- 全局字号阶梯以角色页为基准：页面标题 20 / 弹窗标题 18 / 卡片标题 16 / 正文 13.5 / 辅助说明 13 / 紧凑提示 12 / 单位 11.5，分别使用 `--ui-title-size`、`--ui-modal-size`、`--ui-section-size`、`--ui-body-size`、`--ui-caption-size`、`--ui-compact-size`、`--ui-unit-size`。统计核心数字使用 `--ui-stat-size`（24px）；装备格子、物品图标价格等空间受限区域保留紧凑字号。
- 页面、弹窗、卡片和分区标题使用常规字重，通过字号、深墨色与朱砂竖条突出层级；金额、技能等级和装备名称保留必要的数值或语义强调，不整体合成粗体。
- 装备格子的部位与等级使用 `--equipment-meta-size`（9.5px）并保持单行，名称与属性按全局紧凑层级展示；账本明细表保留最小宽度，日期及金额主体不拆行，窄窗口只在表格内部横向滚动。

## 4. 形状与质感

- 圆角：按钮/输入框 3px，卡片 4px，弹窗 5px。**不得超过 6px**。
- 分层手段按优先级：① 1px 细边框 ② 分割线 ③ 底色差（bg → paper → paper-2 → panel-3）。
- 分区标题和表头不额外添加分割线，通过留白、字重与表头底色区分层级；其他内容分割线使用 1px 单实线，不使用双线或叠加平行线。
- **禁止**：渐变、彩色投影、大阴影。仅弹窗与 Toast 允许一层浅墨投影。
- 底纹：仅 `body` 允许极淡横向纹线（约 3% 不透明度），模拟宣纸；卡片表面为纯色。

## 5. 密度（紧凑账本感）

| 区域 | 规格 |
|---|---|
| 顶栏高 | 56px |
| 侧栏宽 | 展开 200px / 收起 64px |
| 视图内边距 | 16px 20px 28px |
| 表格行 | padding 8px 10px |
| 卡片 | padding 12px 14px |
| 目标卡最小宽 | 320px |

## 6. 图标规范

- **细线性 SVG**：24 viewBox、`stroke-width: 1.6`、`stroke: currentColor`、无填充。
- 尺寸：导航 17px、空状态 30px、正文内 14px。
- **禁止用 emoji 作为界面图标**（文案内也不使用）。
- 表格操作列用文字按钮（编辑 / 删除），不加图标。

全局页面、弹窗、表格、统计卡、目标与设置页共用 `--ui-*` 文字 Token。标题使用深墨色 `#2f2a24`，正文使用棕灰色 `#5b5348`，辅助信息使用暖灰色 `#7b705f`；公共卡片、总览模块及装备分区标题使用与角色页相同的 3×14px 朱砂竖条，间距 8px，不增加标题分割线。页面和弹窗主标题保持简洁，表格列标题与徽章保持紧凑。角色页通过 `--character-*` 引用全局颜色、正文与单位 Token，保留已确认的昵称、分区和辅助字号。

## 7. 组件规范

| 组件 | 规范 |
|---|---|
| 主按钮 | 墨底纸字（`--ink` 底 + 纸色字），像盖印；悬停加深 |
| 次按钮 | 纸底 + 1px `--line-2` 边框 + 墨字 |
| 危险按钮 | 朱砂描边字，悬停淡朱底 |
| 表格 | 账本式：表头以底色区分，不加底线；行间 1px `--line` 细线，悬停纸色加深，无斑马纹 |
| 徽章 | 透明底 + 1px 同色淡边框 + 语义色文字，直角 2px |
| 进度条 | 高 7px、细边框轨道、赭金实心填充（完成为竹青） |
| 分段控件 | 纸底细边框容器；选中项 = 墨底纸字 |
| 侧栏导航 | 选中 = 淡朱砂底色 + 深红图标与文字、常规字重、4px 圆角，无外边框与侧边红线；普通悬停为淡纸底，选中悬停保持朱砂色；收起后选中底为居中的 40px 方形，隐藏品牌文字及底部版本说明。菜单保留悬停名称、键盘操作和无障碍名称，本地记住状态；「设置」使用独立调节图标 |
| 侧栏开关 | 放在菜单栏最底部，与本地保存、版本说明同一行；收起时隐藏说明，开关居中保留。使用侧栏面板 SVG 图标，按当前动作显示展开/收起方向；32×32px 点击区域，默认透明无框，悬停淡纸底，键盘焦点使用赭金轮廓 |
| Logo | 朱砂印章（红底方章 + 纸色衬线“梦”字） |
| 弹窗 | 纸面、细墨边、标题衬线、右上 ✕ |
| 表单 | 输入框纸色 `#fdfaf1`，聚焦赭金描边 + 淡金光环 |
| Toast | 纸片 + 左侧 3px 语义色边 + 浅投影 |
| 空状态 | 虚线框 + 细线 SVG 插图 + 一句引导文案 |
| 标题栏 | 自绘无边框：纸面细线 + 衬线标题；右置最小化/最大化/关闭三枚细线按钮，关闭悬停朱砂底纸色图标；双击标题栏最大化/还原 |
| 下拉选择 | 纸面触发按钮 + 细线下箭头；菜单为纸卡列表（选中项赭金字 + 对钩，悬停淡纸底）；点击外部 / Esc 关闭 |
| 日期选择 | 纸面触发按钮 + 日历细线图标；日历卡：周一起始、今日赭金圆点、选中日朱砂底纸字，支持「今天 / 清除」；空值显示占位灰字 |
| 统计时间筛选 | 前置「本日 / 本周 / 本月 / 本年 / 全部」分段控件，后接开始日期、至、结束日期；复用纸面日历，整组可换行，不新增分割线；手选日期取消快捷项选中，反向区间提示并保留原值 |

## 8. 反模式清单（出现即打回）

- ❌ 渐变按钮 / 渐变卡片 / 渐变进度条
- ❌ emoji 当图标（📊💰🎯⚔️ 之类）
- ❌ 蓝紫默认配色、亮蓝主色
- ❌ 圆角 > 6px、厚重多层阴影
- ❌ 大面积色块、彩色卡片底
- ❌ 无意义装饰元素（玻璃拟态、霓虹发光）

## 9. 落地与维护

1. Token 只存在于 `styles.css :root`，组件样式只引用变量。
2. 新增组件先在本文档补规范，再写样式。
3. 图标统一走 `UI.icon(name)`（`src/renderer/js/core/ui.js`），不散落 SVG。

## 10. 快速记录页（特例组件）

| 组件 | 规范 |
|---|---|
| 计时状态 | 竹青圆点脉动 + 等宽数字 HH:MM:SS |
| 设置胶囊 | 纸底细边框小按钮：细线 SVG 图标 + 文字（角色数 / 点卡价） |

| 战绩面板 | 右栏 300px 吸顶：行式列表（图标 / 名称 / 竹青金额 / 移除），底部合计与跳转 |

## 11. 双账本与物品记录

- 总览按「日常收益 / 账号账本」纵向分区，标题下方不加分割线，通过留白、标题与文字入口区分，不叠加彩色大底。
- 总览两区各自提供统计时间筛选，共用角色筛选；日常收益默认本日，账号账本默认本月。
- 账号账本的人民币与梦幻币分别展示，金额明确标注 ¥ 或万；不可折算混合。
- 收益列表区分「游戏币 / 物品」，物品使用赭金估值和状态徽章，实际成交收入使用竹青。
- 筛选沿用纸面下拉、日历与紧凑分段控件；物品表单按类型显示相关字段。
- 物品掉落仅增加估值；出售生成关联的游戏币收入。删除成交记录时恢复持有，避免重复计入。

## 12. 收益与账号模块

- 侧栏分别提供「收益」「账号」，默认进入对应的快速记录页；记录列表作为模块内二级页面，侧栏始终选中所属模块。
- 两个快速记录页的顶栏提供「查看记录」和本模块记账按钮；列表顶栏提供「返回快速记录」。总览顶栏仅保留角色筛选。
- 收益快速页沿用计时、点卡、物品卡与今日战绩布局。
- 账号快速页顶部提供统计时间筛选，默认本月，按所选范围分别汇总人民币、梦幻币收支；下方左侧为快捷记账卡，右侧为全部时间的最近记录。
- 快捷记账卡使用纸色底、1px 细边框、线性 SVG 图标与文字，通过收支徽章区分方向；点击后打开预填分类、币种与方向的表单。
- 最近账号记录显示日期、角色、内容、币种及实际收付金额，点击可编辑，底部提供完整列表入口。
- 紧凑窗口下快捷区和最近记录纵向排列；标题层级沿用留白，不增加分割线。

## 13. 在线记录

- 收益首页使用默认本日的统计时间筛选；计时操作与统计范围分行，明确显示本次归属角色。
- 「补记在线」与开始/结束游戏并列；计时中提供调整开始时间，未结束记录使用纸色提示条提供继续或补填结束时间。
- 补记表单支持「时间段 / 只填时长」，复用日历与纸面时间输入；底部实时预览在线时长和点卡成本。
- 收益记录内部提供「收益明细 / 在线记录」分段切换；在线记录展示时间、角色数、费用和来源，编辑/删除沿用文字按钮。
- 收益首页在物品区下方显示最近在线记录，统计卡使用「在线时长 / 点卡消耗 / 持有估值 / 净收益 / 在线净时薪」。
- 新增区域沿用留白、细边框与现有 Token，不增加标题或表头分割线。

## 14. 角色装备与三套方案

- 装备首页直接展示全部角色，每角色一张独立装备卡片；宽窗口并排、空间不足自动换行，通过页面上下滚动浏览。移除角色切换与顶栏角色筛选，其他页面的角色筛选独立保留。
- 三套方案收成「1 / 2 / 3」一体式紧凑分段控件，放在人物图标上方，顶部与第一排装备格对齐：共用淡纸底与细外框，各数字等宽；正在查看的方案使用纸底细描边与朱砂加粗数字，当前使用以数字下方的竹青短线标记，不叠加角标圆点。方案全名通过悬停提示和无障碍标签保留，查看与当前使用仍分开。改名、复制和角色仓库入口收在卡片底部。
- 六个常规装备格围绕小号线性角色剪影，人物信息在方案切换下方的剩余空间内居中，只显示角色昵称、等级与门派；昵称使用 16px、600 字重，等级与门派使用 12px，长文字允许换行。角色图标保持原有 48px 尺寸和细线描边，不随文字放大。取消中间印章、服务器和占位说明。四个灵饰格独立成行，阴阳两个玉魄格沿用相同小尺寸；修炼信息横向紧凑展示。
- 格子固定为 96×78px，网格整体宽度约 408px，不随页面拉宽；小号部位图标与等级在上方，名称、首条属性及可选特技在下方。纸面、1px 单实线、3px 圆角；空位为虚线，仅显示部位与添加提示，不重复操作说明。
- 装备名称使用赭金和加粗字重，属性使用黛青与等宽数字，特技/特效使用朱砂和中等字重，宝石与灵尘使用竹青，部位/等级/备注使用次级墨色。格子、属性卡、详情和仓库遵循同一语义色，不另外引入字体资源。
- 悬停与键盘焦点使用赭金描边，不添加投影、渐变或标题分割线。
- 属性浮卡使用纸面细边框，无投影；显示完整录入属性、特技/特效、强化信息与备注，自动避让窗口边缘。悬停、键盘聚焦均可打开，Esc 关闭；点击打开可操作详情。
- 移除右侧配置数量、特技汇总和最近变动；属性在格子和浮卡中查看，时间线保留在装备详情。仓库从所属角色卡片进入，返回时恢复卡片列表的滚动位置；保留搜索、部位/类型/状态筛选和文字操作。
- 玉魄单独录入基础属性、两条附加属性、灵尘等级、特效、开光孔及灵契/祝符、耐久。以手动录入的游戏数值展示，不推算总属性或奇袭概率。
- 三套方案共用装备档案与成本；仓库区分当前穿戴、其他方案备用、未配置及已出售，并标注引用方案。命魂之玉解锁状态、基础属性和修炼等级由角色共用。
- 「新增装备」与「添加角色」统一放在顶部页面标题栏右侧，使用现有墨底主按钮，正文不再重复放置添加工具栏。装备仓库的新增沿用同一入口并预选所属角色。
- 装备与角色页的编辑、修炼设置、仓库、改名、复制等操作使用现有纸底细描边小按钮，默认状态即可识别；删除使用朱砂描边，不使用纯文字 ghost 按钮。数字方案通过共用外框与选中底色呈现为一组切换控件。

## 15. 角色与技能养成

- 角色页沿用装备页的纸面独立卡片：同宽、细边框、4px 圆角，全部角色并排展示，空间不足自动换行并上下滚动，不使用角色切换。顶栏角色筛选在此页隐藏。
- 卡片顶部使用小号线性人物图标、昵称、等级门派和服务器；师门技能、人物/召唤兽修炼、辅助技能分区展示，通过标题和留白分层，不添加标题分割线或记录数量统计。
- 卡片的师门技能、修炼、辅助技能和其他养成标题前统一添加 3×14px 的朱砂红竖条（`--red`），与文字间距 8px、垂直居中、1px 圆角；标题保持常规字重，以竖条增强分区识别。
- 技能名称使用次级墨色，等级使用赭金加粗，修炼等级使用黛青；乾元丹与潜能果使用紧凑数值栏，未记录显示灰色「—」，明确录入的 0 正常显示。
- 角色卡片使用独立的三级文字色 Token：`--character-title` 为深墨色 `#2f2a24`，用于昵称和分区标题；`--character-text` 为棕灰色 `#5b5348`，用于技能/修炼名称及备注；`--character-muted` 为暖灰色 `#7b705f`，用于等级门派、人物/召唤兽小标题、单位和未记录提示。三级文字在纸面上的对比度分别约为 13.3、7.1、4.5，提示文字弱化但保持可读；等级数值沿用赭金和黛青语义色。
- 角色卡片的昵称使用 15.5px，详情名称、数值与备注使用 13.5px，分区标题使用 14.5px 常规字重（400），通过稍大的字号、深墨色与留白区分层级，避免合成加粗显得过厚；等级门派、人物/召唤兽小标题和未记录提示使用 12.5px，数值单位使用 11.5px，保留清晰的阅读层级。
- 角色卡片及新增/编辑、快捷编辑弹窗共用 `--character-title-size`（15.5px）、`--character-section-size`（14.5px）、`--character-body-size`（13.5px）、`--character-caption-size`（12.5px）、`--character-unit-size`（11.5px）和三级文字色。编辑弹窗分区标题使用相同的红色竖条和常规字重；字段标签、列标签与说明使用暖灰色，输入和下拉内容使用棕灰色，行高 1.6。常规操作及输入框至少 36px 高，小按钮至少 30px，技能行操作与输入框等高；统一下拉菜单随角色弹窗采用同一字号。所有样式限定在角色弹窗内。
- 卡片操作集中在顶部，依次放置拖动排序、养成记录、删除和编辑档案的细线 SVG 图标按钮，编辑位于最右侧。排序仅保留一个六点拖动手柄，取消置顶与排序弹窗；保留纸底描边、悬停提示与无障碍名称，删除使用朱砂色。头部空间不足时整组操作换行，不挤压角色名称。
- 角色和目标共用拖动手柄、朱砂插入线、拖动淡化与正文边缘自动滚动；手柄支持方向键前后移动，保存时锁定排序入口，失败恢复原排列，成功恢复原卡片手柄焦点及滚动位置。全部卡片使用一个自由排列的列表，旧置顶按原显示顺序转为普通顺序；顺序随备份及重启保留，新卡片加入列表首位。
- 顶部保留统一档案编辑入口，分区和底部不重复放置编辑图标。师门/辅助技能、人物/召唤兽修炼、乾元丹和潜能果的整行可点击，包括未记录值；静止时沿用原有排版，悬停使用淡纸底和 3px 圆角，文字与底色边缘左右留白 8px、上下留白 2px，通过负外边距保持文字原有对齐及行距，相邻底色之间保留间隔。键盘焦点与整行点击区域共用此边界，使用赭金细描边，提供项目名称和当前值的无障碍标签。
- 单项快捷编辑采用居中的 340px 纸面小弹窗，长角色名与项目名允许换行；显示角色、分区、当前值，使用「− / 数字输入 / ＋」修改，步进为 1，零值禁用减号，打开后聚焦并选中输入。输入数值沿用赭金，修炼使用黛青，仅数字加粗，单位常规字重且间隔 3px；下方实时预览原值→新值。日期默认今天，与本次说明折叠在「补充信息」中。显式保存后生效，Enter 保存，未保存关闭沿用居中放弃确认；保存期间锁定控件，失败保留草稿，成功保留页面滚动并返回原项目焦点。
- 整体编辑弹窗按基础信息、师门技能、人物/召唤兽修炼、辅助技能、其他养成纵向分组，正文滚动、保存按钮固定在底部，全部信息一次保存；失败保留草稿并回滚整个档案。
- 师门技能和辅助技能使用「名称＋等级」可增删列表；辅助技能通过统一的 `UI.select` 选择常用名称，选择「自定义技能」后填写名称，不使用原生 select 或 datalist。等级和数量以游戏实际值手动填写，其他养成保留乾元丹、潜能果与自由备注。
- 档案编辑中的师门、辅助技能按可用宽度排列：技能区达到 580px 时每行两项，否则单列；每项保留名称、紧凑等级框与移除按钮，两列分别对齐列标题。辅助技能下拉填满名称区域，自定义名称在其下方填写，同一行的等级与操作始终顶端对齐。
- 每项技能在等级框右侧提供前移、后移的细线箭头图标和移除按钮；顺序按从左到右、从上到下排列，首项禁用前移、末项禁用后移。排序只改变当前编辑草稿，随统一保存生效；取消、保存失败和自定义辅助技能沿用原有表单规则。
- 档案弹窗标题下方提供固定的紧凑分区定位按钮，正文按明确的基础、师门、人物修炼、召唤兽修炼、辅助、其他分区排列；定位后聚焦对应标题，保存成功返回对应角色的编辑图标。
- 切换门派时，如已有师门技能，在基础信息下方就地提供「保留现有技能 / 替换为新门派技能」选择；未选择前不保存或补齐，切回原门派取消待选提示。替换只修改草稿，不影响其他养成。
- 角色顶栏提供「养成记录」，卡片顶部提供日历图标入口；在统一宽弹窗内按日期倒序查看，支持全部/单个角色、快捷日期及自定义范围，长列表分页。筛选栏将角色选择、快捷日期和起止日期放在同一行，空间不足时自动换行。日期标题沿用朱砂竖条，下方每项变更只占一行，同一行展示角色、分区、项目、原值→新值和变化类型，不再单独显示角色标题、「编辑档案」及变更摘要。复制来源与本次说明收在首项末尾的书页图标，悬停或键盘聚焦查看全文。保持现有字号，长名称和数值省略并可悬停查看全文，窄窗口保持单行。提升使用竹青并显示增量，补录/新增、调低、清空和移除明确标注，不把首次录入当作提升。
- 角色与目标的养成记录共用数值层级：原值用暖灰常规字重，新值用赭金加粗（600），人物/召唤兽修炼的新值用黛青；提升增量用竹青加粗。单位和箭头使用辅助文字色，未记录、清空、移除及门派名称等非数值不加粗或套用数字色。目标历史顶部的当前值、达成人数同步突出；手动进度的增加量用竹青，减少量用赭金，不使用朱砂数字。
- 编辑已有档案时，「其他养成」末尾提供默认今天的变更日期与可选本次说明。等级、门派、技能、修炼和养成数量的实际变化随档案原子保存；新建作为起点，备注、昵称、服务器、排序及无变化保存不产生记录。旧复制记录保留来源，历史随角色备份及删除；记录不提供改写数值的入口。

## 16. 库存、进度与通用交互

- 物品记录分别显示获得数量、剩余数量和已售数量；估值仅计算剩余持有数量。出售弹窗填写本次数量和成交总额，支持分次出售；成交编辑或删除同步恢复对应库存。
- 目标页在顶栏创建目标，提供带计数的状态、类型、搜索和自定义/到期/进度/创建排序，默认自定义排序。卡片顶部仅提供拖动手柄、编辑与删除图标，正文沿用常规字重、纸面及语义颜色。
- 目标沿用角色页的统一拖动交互，不区分置顶组。自动排序模式下拖动会切回自定义排序；筛选时调整只移动目标位置，隐藏目标保留相对顺序。总览遵循相同的自定义顺序。
- 养成目标可选全部或单个角色，默认跟随档案；完整展示每个角色的当前等级或数量与差距，不折叠、不使用局部滚动，未达标成员优先。未知值显示「未记录 / 待补录」，达标用竹青色；全体目标在角色筛选后仍保持完整计算。
- 创建表单按进度来源显示相关字段，使用统一下拉与日历，自动选择养成单位并预览达标情况；名称可留空生成。全部角色包含后续新增角色。目标页可批量填写实际养成值，写回角色档案及变更记录，自动判断完成与恢复。
- 存钱/装备目标以所选角色共同累计，不将目标金额乘以角色数。完成日期使用实际完成时间；「进度历史」支持查看、编辑或删除单次进度。跟随目标的「养成记录」只读展示对应项目的角色变更，删除目标保留角色数据。
- 角色与目标历史共用日期范围及每页 12 条的分页交互，筛选只作用于当前弹窗；角色按变更事件分页，目标按记录行分页。目标保留表格，养成变化与角色页统一显示新增、移除、补录、清空、提升、调低和调整，提升量使用竹青。删除手动进度后保留原日期范围和页码，页数减少时回到有效页。
- 师门技能编辑提供「补齐门派技能」，按表单当前门派补齐，保留已有等级与自定义技能。
- 收益和账号列表的筛选栏提供「导出 CSV」，导出全部符合当前筛选的记录，不限于当前分页；沿用纸底描边次按钮。
- 下拉支持方向键、Home/End、Enter 和 Esc，选项使用统一选中与焦点样式；弹窗限制键盘焦点并在关闭后恢复原焦点。Esc 优先关闭下拉或日历，再关闭弹窗。
- 修改过的表单关闭前在原弹窗中央显示放弃确认，纸面提示卡明确展示「放弃未保存的修改？」与关闭后丢失的说明，使用正文大小及常规按钮；下层表单淡化并暂停交互，不在表单底部追加提示，也不新增独立弹窗。默认聚焦「继续编辑」，Tab 只在两项操作间切换；Esc 返回编辑，恢复草稿、滚动位置和原操作焦点。「放弃修改」才关闭弹窗，未修改时直接关闭；保存过程中阻止重复关闭或提交。新增区域使用现有色板与留白，不增加标题分割线、投影或渐变。
- 保存期间锁定弹窗内全部输入及操作，显示保存中状态；失败恢复各控件原有可用状态并保留草稿。异步操作仅刷新所属页面，避免切页后覆盖正文；弹窗关闭时支持按稳定的角色 ID 恢复操作焦点。
- 通用表单先校验可见数字输入的原始有效性，再读取数值；不完整数字不能视为留空，范围和步长以当前字段约束为准。主动留空仍表示未记录，明确的 0 正常保存；错误输入也计入未保存草稿。

- 目标卡片的进度百分比、当前/目标值和达成角色数仅数字使用 `font-weight: 600` 与 `tabular-nums`；级、个、万、元、百分号等单位独立显示，沿用角色页的辅助文字色、单位字号与常规字重（400），不随数字加粗。角色卡片、目标卡片及两处养成记录的数字与单位统一间隔 3px，空单位不留间隔。当前/达成值与剩余差距使用角色页同款赭金，角色养成当前值使用黛青，目标/总数使用深墨，未记录与待补录使用辅助文字色，已达标状态使用竹青。目标状态等分段按钮保持文字单行，紧凑卡片底部操作保留 6px 间距。

## 17. 装备截图录入

- 装备顶栏在「新增装备」旁提供「截图录入」次按钮；装备空格的选择弹窗也可直接截图录入，沿用角色、部位与方案。
- 使用一个宽弹窗完成全部操作：顶部角色和保存位置，空态为截图拖放区，支持 Ctrl+V、选择多张图片；每张图片只包含一件装备属性浮窗。添加后自动在本机识别，不增加识别确认步骤。
- 有图片时左侧为紧凑缩略图列表，中间为可裁剪原图，右侧为可直接修改的识别字段；窄窗口中原图与字段纵向排列，底部保存按钮固定。界面沿用现有纸面、常规字重、文字颜色与朱砂分区标题，不出现算法参数。
- 识别结果只作为待保存草稿，缺失字段明确提示；保留识别原文供展开核对。同名多条属性保留原顺序，不猜测缺失数值；玉魄按现有独立字段校验。
- 一次保存全部已完成识别的草稿，复用事务保存与失败回滚。默认只填所选方案的空位，已有装备与同部位多件保留入库并就地说明；不生成账本收支或交易变动。
- 相同截图在本次队列内去重；已有同角色、同部位且全部录入字段相同的装备直接复用。保存中锁定操作，关闭未保存草稿仍使用现有放弃确认。
- 空文字结果显示「未识别到文字」并提示裁剪重试，不显示识别成功，也不增加确认步骤。
