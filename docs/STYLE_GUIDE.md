# 梦幻养老助手 · 界面风格规范（STYLE_GUIDE）

> 一句话定调：**一本摊开的宣纸账本**——墨字、朱砂、竹青、赭金，细线分区，无渐变、无阴影、无 emoji。
> 本文档是样式改动的唯一依据：先改文档，再改 `styles.css` 的 Token，最后才动组件。

---

## 1. 设计关键词

宣纸 · 账本 · 墨字 · 印章朱砂 · 细线 · 紧凑

## 2. 色板（Design Tokens）

所有 Token 定义在 `src/renderer/styles.css` 的 `:root`，改风格只改这里。

### 纸与墨（中性色）

| Token | 值 | 用途 |
|---|---|---|
| `--bg` | `#f2ecdd` | 页面底（米白宣纸） |
| `--paper` / `--panel` | `#fbf7ec` | 卡片、顶栏、弹窗表面 |
| `--paper-2` / `--panel-2` | `#f5efdf` | 次级表面、表头、悬停 |
| `--panel-3` | `#ece3cc` | 侧栏、深层表面 |
| `--ink` / `--text` | `#2f2a24` | 主文字（墨黑，非纯黑） |
| `--ink-2` | `#6b6353` | 次级文字 |
| `--ink-3` / `--muted` | `#9a917e` | 弱化文字、提示 |

### 线

| Token | 值 | 用途 |
|---|---|---|
| `--line` / `--border` | `#d9cfb6` | 常规边框、表格行线 |
| `--line-2` / `--border2` | `#c2b58f` | 强调边框、输入框、表头双线 |

### 语义色（全站仅此四类彩色）

| Token | 值 | 用途 |
|---|---|---|
| `--green` | `#4a7c59` | 收入、成功、已完成 |
| `--red` | `#b33a3a` | 支出、危险、侧栏选中标记 |
| `--gold` / `--gold2` | `#a67c2e` / `#8a6322` | 高亮、进度、排行、焦点 |
| `--blue` | `#3d5a6c` | 养成目标徽章（黛青，非亮蓝） |
| `--purple` | `#8a5a2b` | 装备目标徽章（赭石） |

**禁止出现的颜色**：蓝紫渐变、亮蓝 `#3b82f6`、霓虹色、大面积纯黑 `#000` / 纯白 `#fff`。

## 3. 字体

全局使用内置开源字体 **霞鹜文楷屏幕版**（LXGW WenKai Screen v1.530，OFL 1.1 许可，允许随应用分发、免费商用）：

| 场景 | 字体栈 |
|---|---|
| 全局正文 / 标题 / 数字 | `"LXGW WenKai Screen" → "Microsoft YaHei" → sans-serif`（`--font-body` 与 `--font-serif` 同源，保留双变量便于日后分化） |

- TTF 内置于 `src/renderer/assets/fonts/`，通过 `@font-face` 本地加载，不联网、不依赖系统字体。
- 单一 Regular 字重内置；`font-weight: 600/700` 由浏览器合成加粗（勿在 @font-face 声明全字重区间，否则会禁用合成粗体）。
- 数字保持 `font-variant-numeric: tabular-nums` 声明（字体不支持时自动回退比例数字）。
- 字号阶梯：页面标题 17 / 卡片标题 14 / 正文 12.5 / 表格 12 / 徽章提示 11。

## 4. 形状与质感

- 圆角：按钮/输入框 3px，卡片 4px，弹窗 5px。**不得超过 6px**。
- 分层手段按优先级：① 1px 细边框 ② 分割线 ③ 底色差（bg → paper → paper-2 → panel-3）。
- **禁止**：渐变、彩色投影、大阴影。仅弹窗与 Toast 允许一层浅墨投影。
- 底纹：仅 `body` 允许极淡横向纹线（约 3% 不透明度），模拟宣纸；卡片表面为纯色。

## 5. 密度（紧凑账本感）

| 区域 | 规格 |
|---|---|
| 顶栏高 | 56px |
| 视图内边距 | 16px 20px 28px |
| 表格行 | padding 6px 10px |
| 卡片 | padding 12px 14px |
| 目标卡最小宽 | 280px |

## 6. 图标规范

- **细线性 SVG**：24 viewBox、`stroke-width: 1.6`、`stroke: currentColor`、无填充。
- 尺寸：导航 17px、空状态 30px、正文内 14px。
- **禁止用 emoji 作为界面图标**（文案内也不使用）。
- 表格操作列用文字按钮（编辑 / 删除），不加图标。

## 7. 组件规范

| 组件 | 规范 |
|---|---|
| 主按钮 | 墨底纸字（`--ink` 底 + 纸色字），像盖印；悬停加深 |
| 次按钮 | 纸底 + 1px `--line-2` 边框 + 墨字 |
| 危险按钮 | 朱砂描边字，悬停淡朱底 |
| 表格 | 账本式：表头下方 **3px 双线**，行间 1px 细线，悬停纸色加深，无斑马纹 |
| 徽章 | 透明底 + 1px 同色淡边框 + 语义色文字，直角 2px |
| 进度条 | 高 7px、细边框轨道、赭金实心填充（完成为竹青） |
| 分段控件 | 纸底细边框容器；选中项 = 墨底纸字 |
| 侧栏导航 | 选中 = 纸色底 + 左侧 2px 朱砂内嵌线 |
| Logo | 朱砂印章（红底方章 + 纸色衬线“梦”字） |
| 弹窗 | 纸面、细墨边、标题衬线、右上 ✕ |
| 表单 | 输入框纸色 `#fdfaf1`，聚焦赭金描边 + 淡金光环 |
| Toast | 纸片 + 左侧 3px 语义色边 + 浅投影 |
| 空状态 | 虚线框 + 细线 SVG 插图 + 一句引导文案 |
| 标题栏 | 自绘无边框：纸面细线 + 衬线标题；右置最小化/最大化/关闭三枚细线按钮，关闭悬停朱砂底纸色图标；双击标题栏最大化/还原 |

## 8. 反模式清单（出现即打回）

- ❌ 渐变按钮 / 渐变卡片 / 渐变进度条
- ❌ emoji 当图标（📊💰🎯⚔️ 之类）
- ❌ 蓝紫默认配色、亮蓝主色
- ❌ 圆角 > 6px、厚重多层阴影
- ❌ 大面积色块、彩色卡片底
- ❌ 无意义装饰元素（玻璃拟态、霓虹发光）

## 9. 落地与维护

1. Token 只存在于 `styles.css :root`，组件样式只引用变量。
2. 新增组件先在本文档补规范，再写样式。
3. 图标统一走 `UI.icon(name)`（`src/renderer/js/core/ui.js`），不散落 SVG。

## 10. 快速记录页（特例组件）

| 组件 | 规范 |
|---|---|
| 计时状态 | 竹青圆点脉动 + 等宽数字 HH:MM:SS |
| 设置胶囊 | 纸底细边框小按钮：细线 SVG 图标 + 文字（角色数 / 点卡价） |
| 物品卡 | 62px 纸色小卡：游戏图标 42px（`image-rendering: pixelated`）+ 下方赭金单价，未设价为灰字 |
| 物品交互 | 左键快速记录、右键弹窗改价（显示单位万，存储换算为梦幻币，与网页版单价文件互通） |
| 战绩面板 | 右栏 300px 吸顶：行式列表（图标 / 名称 / 竹青金额 / 移除），底部合计与跳转 |
| 数据打通 | 每次物品点击生成一笔「物品掉落」收入记录；结束游戏按 `小时 × 点卡价 × 6 × 角色数` 生成「点卡」支出 |
