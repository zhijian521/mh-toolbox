# 双账本与物品结算规则

## 账本归属

- **收益记录**（`ledger: earnings`）：日常游戏币产出、掉落物品、出售掉落、点卡消耗、药品和修理成本。
- **账号账本**（`ledger: account`）：自用装备/召唤兽交易、藏宝阁交易、点卡充值、买卖游戏币和养成投入。
- 快速记录归收益记录；装备页同步的买卖/打造/宝石支出归账号账本。
- 普通游戏币记录可通过「转账本」调整归属。人民币、储备金、物品、出售结算及关联装备记录不提供直接转账本，避免丢失单位或关联关系。

## 金额与统计

| 字段 | 约定 |
|---|---|
| `currency: cash / reserve` | 梦幻币现金 / 储备金，金额单位为万 |
| `currency: rmb` | 人民币，金额单位为元 |
| `amount` | 游戏币金额或账号成交金额；物品记录中为参考总估值 |
| `fee` | 与账号成交金额币种一致，收入扣除、支出加上 |
| `recordType: money / item` | 实际游戏币 / 掉落物品；账号流水始终为 money |

日常净收益 = 游戏币收入 − 日常成本；物品估值不参与净收益与时薪。在线净时薪 = 所选角色与日期范围内游戏币净收益 ÷ 已记录在线时长，无在线记录显示「—」。单笔流水的活动用时保留展示，不再加入在线时长。

账号人民币与梦幻币分别统计。人民币显示总投入、总回款、净支出；梦幻币显示交易支出、交易收入、收支差额。这里的收支差额不代表资产交易利润，不自动折算币种。

总览两区共用角色筛选，时间范围各自独立：收益默认本日、账号默认本月，流水统计、趋势和最近记录跟随各区所选范围。账号首页的收支统计默认本月，可独立调整；右侧最近记录展示全部时间，便于快速编辑。

统计时间筛选前置「本日 / 本周 / 本月 / 本年 / 全部」，后接开始与结束日期；手选日期进入自定义范围，包含起止两天，清除某个日期表示不限该边界。反向区间提示并保留原值。页面切换、角色切换和记账后保留本次选择。

持有物品估值显示当前持有资产，仅受角色筛选影响，界面会明确标注。

充值点卡是人民币投入；实际在线消耗的点卡是日常游戏币成本。它们分别出现在两类账本，不能跨币种合并。

## 在线记录与点卡

- 自动计时和手动补记统一保存在 `sessions`；补记可填写完整起止日期时间，或仅填写某天的小时与分钟。只填时长不检查时段重叠，界面明确提示。
- 每段记录保存归属角色、角色数、点卡价格、时长及来源。五开 3 小时仍为 3 小时，费用为 `小时 × 6 点 × 角色数 × 梦幻币/点 ÷ 10000`，单位为万。
- 时间段按本地午夜分成每日片段，按实际分钟分摊时长、点卡费用；每日费用按累计比例舍入，合计等于整段费用。同一归属的时间段不可重叠，邻接可保存；未来与反向时间被拒绝。
- 保存生成带 `sessionId` 的收益点卡支出，一天一笔；在线记录修改会重建对应每日流水，删除同步移除整段流水。收益明细中编辑点卡也打开在线表单，不能转入账号账本。
- `activeSession` 在开始时即持久化，并固定归属角色、角色数和价格，修改全局设置用于下一段。计时中可调整开始时间；结束写入失败保留原计时，方便重试。
- 普通重启发现未结束记录时，等待用户选择继续或补填实际结束时间；选择继续会包括应用关闭期间的时间。开发热刷新可自动续计。
- 收益首页默认本日，统计可自定义日期范围，包含正在计时的预估时长和成本；总览按已保存记录统计，口径有明确文案。
- 旧版 `source: quick`、分类点卡且含在线分钟的支出转换为历史在线记录，保留原日期、时长及费用；缺失的角色数、价格及起止时间不推测，手动记的普通点卡不自动转换。

## 物品流程

1. 获得物品：记录 `itemName / quantity / unitPrice / status`，按数量乘参考单价展示估值。状态为 `held`（持有）或 `self`（自用）。
2. 整笔出售：按实际成交总额生成一条 `money` 游戏币收入（`itemRecordId` 指向获得记录），物品变为 `sold` 并保存 `saleId`。
3. 重复出售会被拒绝；出售日期不能早于获得日期。第一版不支持拆分数量出售。
4. 删除成交记录：物品恢复持有，撤销实际收入；删除已出售的物品获得记录会连同成交收入一起删除，操作前有提示。
5. 快速记录里的「金币」直接计入游戏币收入，其余物品只增加估值。单价库仍以原始梦幻币存储，与旧版单价文件兼容。

## 装备关联

账号记录可关联所属角色的装备档案，保存后生成一条带 `transactionId` 的装备变动日志。编辑收支会更新同一关联日志，避免重复记入；删除收支会删除关联日志并根据剩余买卖记录恢复装备状态。

删除装备档案会删除时间线，但保留账号收支并解除关联。装备页也支持不记账、只记变动。

## 旧数据兼容

数据版本升级为 `schemaVersion: 3`，仍使用一个本地 JSON 文件；新增在线记录与未结束计时。

- 明确的装备购入、打造或旧版装备同步流水归账号账本。
- 点卡充值分类及明确的人民币记录归账号账本。已有金额和币种保留，不猜测人民币换算。
- 旧快速记录的物品收入改为物品估值，金币仍为实际游戏币。
- 无法明确识别的记录保留在收益记录，可手动调整归属。
- 装备名、角色、日期、动作和金额均吻合时，补齐旧装备日志与流水的关联。
- 首次将旧数据保存为新版之前，在数据目录复制 `data.json.before-ledgers-时间戳.bak`。迁移重复执行不会增加记录。
- 从版本 2 升级在线记录前，自动复制 `data.json.before-online-时间戳.bak`；原金额保持不变，迁移可重复执行。

## 验证

- `npm test`：数据迁移、独立统计、出售与撤销、装备同步、在线跨天分摊、参数快照、保存失败重试和备份往返。
- `npm run test:electron`：真实 Electron + preload + IPC，使用系统临时目录，检查两类账本、在线补记/编辑/删除、重叠校验、时间统计、两次重载恢复、备份及落盘，不修改日常数据文件。
- `npm run shots`：生成总览、收益、目标、快速记录、账号账本、在线列表和补记表单截图，示例只在内存加载。
