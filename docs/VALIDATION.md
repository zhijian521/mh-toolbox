## 删除确认改为独立弹窗

日期：2026-10-27。范围：账号记录与目标进度记录的删除确认，以及 BaseModal 的叠层支持。

| 检查              | 结果                         |
| ----------------- | ---------------------------- |
| 格式化            | `prettier --check .` 通过    |
| ESLint            | 0 错误 0 警告                |
| 类型检查          | `vue-tsc --noEmit` 0 错误    |
| 领域与隔离测试    | 95 项通过 0 失败             |
| Vite 生产构建     | 通过                         |
| Electron 集成流程 | PASS，新增叠层与 Escape 断言 |

两处删除确认原本是列表里的内联确认条，理由是「弹窗叠弹窗会抢 Escape」。现在把这个前提修掉了，确认改成独立弹窗，叠在记录列表之上。

新增 `components/modal-layer.ts` 维护弹窗层级，`BaseModal` 据此处理三件事：

1. **Escape 与 Tab 只由最上层响应。** 每个实例都在 document 捕获阶段监听 keydown，之前不判层时，先注册的外层会先收到 Escape 并关掉自己，内层确认框留在原地。
2. **背景 inert 由最外层统一设置与移除。** 之前每层各设一次，内层关闭时 `removeAttribute('inert')` 会把外层的 inert 一起清掉。
3. **非最上层面板整块 `inert`。** 被盖住的内容既不能聚焦，读屏也不会读到。

确认弹窗的 `autofocus` 放在「取消」上，初始焦点不落在危险按钮，误按回车不会删除。

集成测试新增三处断言：打开确认后 `.modal` 数量为 2；按 Escape 后回到 1 且记录列表仍在；确认删除后确认弹窗关闭、回到列表。这是叠层最容易出错的两个点（层数没退出、或者连外层一起关掉）。

焦点回落：删除成功后被删那行连同按钮一起消失，`previous` 已断开，改为聚焦记录列表首项，不会掉到文档开头。
