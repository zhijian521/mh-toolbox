# 更新日志

本项目所有显著变更都记录在此（新版本在前）。

## [Unreleased]

### 变更
- 项目结构重构：主进程拆分为 `main / ipc / screenshot` 三模块；渲染层 JS 分为 `core / layout / views`；字体与图片归入 `assets`；文档独立为 `docs`。
- 截图工具输出迁移至 `docs/screenshots`。

### 新增
- `docs/ARCHITECTURE.md` 架构与扩展指南、本更新日志。
- 提交信息规范（Conventional Commits 风格：`type: 简短描述`）。
- 字体随包附带 OFL 1.1 许可文本。

## [0.1.0] - 2026-10-23

### 新增
- 初版功能：快速记录（在线计时/点卡/物品掉落）、收益记录、目标、装备档案与变动时间线、多角色、总览统计、备份导入导出。
- 宣纸账本视觉规范（`STYLE_GUIDE.md`）与配套深浅一致的组件体系。
- 自绘无边框标题栏（拖拽/双击最大化/朱砂关闭）。
- 内置霞鹜文楷屏幕版字体，全局应用。
- Electron 打包：NSIS 安装版 + 便携版。
