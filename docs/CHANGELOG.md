# 更新日志

## 2026-10-25 · 可收起侧栏与设置入口

- 「备份与设置」统一改为「设置」，使用独立调节图标。
- 菜单栏底部的侧栏面板图标支持展开和仅图标模式，透明按钮悬停显底；选中项使用淡朱砂底与深红图文，移除外框及红线，收起时为居中方形。
- 保留选中状态、菜单名称提示及键盘操作，重启恢复本机偏好；侧栏底部显示本地保存、版本信息与开关，收起后开关居中保留。
- 展开/收起只调整布局，保留页面、计时、筛选和业务数据；补充设置导航、焦点及真实重载回归。

## 2026-10-25 · 角色养成变更记录

- 保存角色档案时自动记录等级、门派、技能、修炼及乾元丹/潜能果的实际变化，保留前后值，区分提升、新增/补录与调整；首次建档作为起点，技能重排及资料备注修改不产生记录。
- 角色页顶栏和卡片日历图标可查看历史，按日期倒序分组，支持角色、快捷日期、自定义区间及分页；编辑档案可补选变更日期和本次说明。
- 复制养成记录来源，变更与档案整体保存及回滚；历史随备份和角色删除管理。
- 列表将角色和变更明细合为单行，角色与日期筛选并排；修正同毫秒保存时的记录顺序，过滤备份中的异常日期。
- 增加领域和真实 Electron 回归，覆盖空值/零值、补录、复制、失败重试、筛选、分页、焦点、重启及窄窗口。

## 2026-10-25 · 实际游戏截图识别修复

- 改为本地 PP-OCRv4 检测与中文识别，保留半透明背景中的彩色文字，移除整图灰度反色。
- 修正空文字仍当作成功的问题，显示明确的未识别提示并保留手动补录和裁剪重试。
- 完善游戏内等级、灵饰类型、精炼与混合宝石行解析；限定部位和等级纠正「明月珰」生僻字误读。
- 使用三张实际游戏截图验证名称、部位、等级、属性、特技与批量字段回填，增加空图片回归。

## 2026-10-25 · 装备截图批量录入

- 装备顶栏与格子选择增加截图入口，支持 Ctrl+V、拖入多张图片和文件选择，添加后自动本地识别。
- 原图与可编辑字段并排核对，支持裁剪重识别、队列去重、名称 / 部位补全与识别原文保留。
- 默认补齐所选方案空位，已有装备保留，多余装备与未解锁玉魄入仓库；完全相同档案复用，不产生收支。
- 引擎与中文模型随包离线运行，独立进程处理并支持取消、超时和空闲释放。批量保存整体回滚，失败可保留草稿重试。
- 增加文字解析、玉魄、去重与重启、写入失败、真实 OCR、粘贴 / 拖放 / 裁剪及窄窗口测试，验证打包后的识别进程与模型加载。

## 2026-10-25 · 角色编辑与复制完善

- 师门与辅助技能按空间自适应双列，支持前移、后移，顺序随统一保存和备份保留。
- 档案编辑按明确分区组织，增加固定分区导航；切换门派时选择保留已有技能或替换为新门派模板。
- 复制养成增加当前值与复制后值预览，默认跳过未记录项，保留目标独有技能并正常复制 0；支持关闭跳过以完整覆盖。
- 保存期间锁定整个表单，失败恢复草稿和控件状态，成功后恢复对应角色操作焦点。
- 修复置顶、删除等待期间切换页面后正文被角色卡片覆盖的问题；已有档案保存不再计算新建位置。
- 补充分区导航、门派选择、复制预览、异步切页、保存锁定及失败重试的回归验证。

## 2026-10-25 · 角色卡片与统一档案

- 角色卡片支持置顶与组内排序，重启和备份恢复后保留；新角色加入普通组首位。

- 基础信息、师门/辅助技能、人物/召唤兽修炼及其他养成统一编辑，一次校验保存，失败完整回滚并保留草稿。
- 补充排序、完整档案保存、失败重试、真实重启、窄窗口与图标入口的回归验证。
