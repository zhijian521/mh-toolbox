# 更新日志

本项目所有显著变更都记录在此（新版本在前）。

## [Unreleased]

### 变更
- 装备与角色的添加入口移到顶部标题栏；编辑、改名、复制、修炼等操作统一使用纸底描边按钮，删除使用朱砂描边，数字方案增加可见边框。
- 角色页改为与装备页一致的独立卡片，展示全部角色并自适应换行；按养成分区编辑，移除旧记录数量统计；角色创建、编辑与删除失败时回滚，保留输入并支持重试。
- 装备页直接展示全部角色卡片，自适应并排和换行；三套方案改为人物图标上方的数字按钮，移除角色切换和右侧摘要，仓库从对应角色卡片进入。
- 装备页简约化：固定小格子、精简角色中心与侧栏摘要；角色头像文字切换与方案分段按钮分开，装备名称、属性、特技和强化信息采用统一语义色与字重区分。
- 装备首页重构为角色装备栏，保留模块内部仓库、搜索和变动时间线；资产持有与方案穿戴分开，售出/删档清理全部引用，历史冲突保留并提示确认。
- 总览收益默认本日、账号默认本月，各区独立选择统计范围；账号首页默认本月，统一提供前置快捷项与起止日历，支持自定义范围。
- 导航收拢为「收益」「账号」两个记账模块，默认进入快速记录，完整列表通过模块内入口打开；总览移除新增记账按钮。
- 表头与总览分区标题取消分割线，通过底色、标题和留白区分层级。
- 项目结构重构：主进程拆分为 `main / ipc / screenshot` 三模块；渲染层 JS 分为 `core / layout / views`；字体与图片归入 `assets`；文档独立为 `docs`。
- 截图工具输出迁移至 `docs/screenshots`。

### 新增
- 角色养成档案：师门技能、人物五项修炼、召唤兽四项修炼、辅助技能、乾元丹、潜能果与养成备注。技能自定义增删，空值和零值分开，旧档案兼容、备份及重启完整保留。
- 每角色三套装备搭配、复制/改名/独立切换与当前使用标记；常规装备、灵饰和阴阳玉魄共十二个槽位，悬停和键盘聚焦查看属性。
- 玉魄基础/附加属性、灵尘、开光、特效与耐久录入；角色共用命魂之玉修炼，强化支出与账号账本联动。版本 4 升级自动备份，装备领域及真实 Electron 流程覆盖写入失败重试、旧数据兼容和重启恢复。
- 在线记录统一自动计时和手动补记，支持时间段/只填时长、开始时间调整、列表编辑删除、跨天分摊及点卡成本联动；每段保存角色与价格快照，未结束计时重启后可恢复。
- 收益首页支持时间范围统计与在线净时薪；旧在线点卡迁移保留原金额，升级前自动备份。增加领域及真实重载恢复测试。
- 账号快速记录页：常用交易预填、分币种汇总、最近记录编辑与模块内列表返回；补充导航与快捷记账流程回归测试。
- 双账本：收益记录与账号账本独立展示、筛选及统计；人民币与梦幻币分开汇总。
- 物品获得、参考估值、出售结算与撤销；快速记录同步采用物品估值口径。
- 账号交易支持渠道、手续费和装备关联，装备页记账同步到账号账本。
- 总览按日常收益与账号收支分区，支持共同的角色筛选、独立日期范围及趋势。
- 旧数据迁移与自动备份，记账领域和真实 Electron 流程回归测试。
- `docs/ARCHITECTURE.md` 架构与扩展指南、本更新日志。
- 开发模式热更新 `npm run dev`：CSS 免刷新替换、页面自动刷新并恢复状态、main/preload 变更提示重启。
- 自定义下拉选择与日历日期组件，替换全部原生 select/date 控件，风格与宣纸账本规范一致。
- 丰富示例数据生成器（3 角色 / 45 天流水 / 目标 / 装备 / 单价），新增 `npm run demo` 一键写入。
- 提交信息规范（Conventional Commits 风格：`type: 简短描述`）。
- 字体随包附带 OFL 1.1 许可文本。
