# 梦幻养老助手

梦幻西游养老记录日志桌面应用。Electron + 原生前端，宣纸账本视觉风格，内置霞鹜文楷字体，数据全部本地保存。

## 功能

- **收益**：默认进入快速记录，支持自动计时、在线手动补记、点卡消耗计算、59 种物品掉落速记与手动记账；默认本日，可自选范围统计在线时长与净时薪；模块内管理收益明细和在线记录，支持跨天分摊、编辑联动与计时恢复
- **账号**：装备、召唤兽、点卡充值、游戏币买卖和养成投入快捷记账；默认本月，支持快捷与自定义日期范围，人民币与梦幻币分别汇总，支持最近记录编辑与完整账号记录列表
- **目标**：支持全部或单个角色；技能、人物/召唤兽修炼、等级与养成数量跟随角色档案，完整展示全部角色差距和自动达标，支持批量更新与养成记录；目标卡片可置顶、拖动排序，存钱/装备目标手动累计，提供搜索、类型/状态筛选与到期排序
- **装备**：全部角色独立卡片，三套搭配独立换装；按部位录入主要属性、双加、特技特效及宝石，灵饰与阴阳玉魄使用各自字段；放大格子完整显示属性、重复词条与强化加成，支持截图录入、角色仓库、更新时间线及账号账本联动
- **角色**：全部角色独立卡片，支持拖动排序；统一档案按分区定位，技能支持自适应双列和前后排序，转门派可选择保留或替换师门技能；保存自动记录养成变化，可按角色和日期查看提升明细，顺序、档案和历史随备份恢复
- **总览**：收益默认本日、账号默认本月，各自支持日 / 周 / 月 / 年 / 全部及自定义日期范围；展示分类排行、趋势与目标进度，可进入对应快速记录页
- **设置**：数据概览、JSON 备份导出 / 导入 / 清空与应用信息

左侧菜单可通过菜单栏底部的面板图标收起或展开，收起后只显示图标，悬停显示菜单名称；展开状态在本机记住，重启后恢复。

新增支持物品分次出售与剩余库存、目标进度历史、门派技能模板，以及筛选导出 CSV。统一下拉支持键盘，表单关闭提供未保存提醒。

角色页顶栏的「养成记录」查看全部角色历史，卡片上的日历图标只看该角色。等级、门派、师门/辅助技能、人物/召唤兽修炼、乾元丹与潜能果发生变化时，保存会自动生成原值→新值记录；编辑档案底部可选实际变更日期与本次说明。提升、新增/补录和调整分别标注，首次建档作为起点，已有档案从下一次实际变化开始记录。

## 装备截图录入

在装备页点击「截图录入」，粘贴、拖入或选择装备属性截图，识别后对照原图核对，点「保存 N 件」一次完成。每张图包含一件装备属性，每批最多 30 张；全屏截图可在预览中裁剪后重识别。手动新增和截图核对共用按部位变化的属性表单，特技可搜索；切换部位或图片保留草稿，无法识别的内容保留供核对，识别原文随档案保存。数值按游戏显示值记录，不反算宝石与灵尘加成。字段规则与兼容方式见 [装备属性说明](docs/EQUIPMENT_FIELDS.md)。

默认沿用当前角色和正在查看的方案，只补空位，已有装备保留；同部位多余的装备及未解锁的玉魄放入仓库，也可选择「仅存入仓库」。完全相同的档案会复用。截图识别不产生收支或交易记录。

OCR 引擎和中文模型随应用安装，无需插件、密钥或网络，图片只在本机内存中处理。游戏字体、压缩和复杂背景会影响识别，请重点核对名称和数值。

## 开发

```bash
npm install
npm run dev      # 开发模式（热更新：CSS 免刷新 / 页面自动刷新）
npm start        # 普通运行
npm test         # 领域规则与迁移回归
npm run test:electron # 真实 Electron 流程，数据写系统临时目录
npm run check    # JS 语法检查
npm run smoke    # 冒烟自检（启动 1.2s 自动退出）
npm run shots    # 注入示例数据并截图到 docs/screenshots
npm run demo      # 写入一套完整示例数据到本地（覆盖当前数据）
npm run dist     # 打包安装版 + 便携版（输出 dist/）
```

## 数据与许可

- 用户数据保存在本机 `%APPDATA%/梦幻养老助手/data.json`，不上传任何服务器。
- 内置字体：[霞鹜文楷屏幕版 LXGW WenKai Screen](https://github.com/lxgw/LxgwWenKai-Screen)（OFL 1.1），许可文本见 `src/renderer/assets/fonts/OFL.txt`。
- 本地识别：[Guten OCR](https://github.com/gutenye/ocr)（MIT）、[PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR) 模型（Apache 2.0）与 ONNX Runtime（MIT），模型随包提供。
